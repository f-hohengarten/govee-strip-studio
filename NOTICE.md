# Govee Strip Studio

Eigene Integration auf Basis von **ha-govee-led-ble** von teh-hippo
(https://github.com/teh-hippo/ha-govee-led-ble, Version 7.34.0, MIT-Lizenz, siehe LICENSE).

Ergänzt um: Strip Studio (strip_studio.py, studio_render.py, studio_frontend/panel.js) –
Streifen-Geometrie (Anfang, Ende, Zentrum), Effekte (statisch, Segmente, Verlauf, Fade,
Marquee) mit Richtungen und eigenem Seitenleisten-Bereich. Verbindung standardmäßig „hold“.
